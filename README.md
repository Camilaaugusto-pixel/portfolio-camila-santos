# Portfólio Pessoal – Camila Santos

*Aluna:* Camila Santos

## Descrição do Projeto

Este projeto é um portfólio pessoal desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas.

O objetivo é apresentar um pouco sobre mim, minhas habilidades, meus projetos acadêmicos e meus conhecimentos na área de tecnologia.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Bootstrap)
- GitHub Pages

## Estrutura do Portfólio

O site possui as seguintes seções:

- *Perfil:* apresentação pessoal e profissional.
- *Habilidades:* apresentação das tecnologias que estou aprendendo.
- *Projetos:* apresentação de atividades desenvolvidas durante o curso.
- *Contato:* acesso ao meu perfil no GitHub.

O menu de navegação permite acessar cada seção do site por meio de links.

## Recurso Novo Adicionado

O recurso novo implementado foi a animação nos cartões da seção de projetos.

Ao passar o mouse sobre os cartões, eles apresentam um movimento para cima, um leve aumento de tamanho e uma sombra mais destacada.

## Como o Recurso Foi Implementado

A animação foi desenvolvida utilizando CSS, por meio das propriedades transition, transform e box-shadow.

A propriedade transition permite que a mudança aconteça suavemente. Já o transform movimenta e aumenta levemente o cartão, enquanto o box-shadow modifica a sombra.

Esse recurso deixa o portfólio mais moderno e melhora a experiência de quem acessa o site.

## Funcionamento do Projeto

O portfólio foi desenvolvido com HTML para organizar o conteúdo, CSS para personalizar o visual e Bootstrap para auxiliar na organização das seções e na adaptação do site a diferentes tamanhos de tela.

O menu permite navegar entre as seções Perfil, Habilidades, Projetos e Contato.
